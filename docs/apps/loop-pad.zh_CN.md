# LOOP PAD —— 口袋嘴鼓循环采样器

LOOP PAD 把 FoloToy AI Passport 变成一台四轨 lo-fi 采样器:对着内置麦克风打嘴鼓,
设备把它录成循环,你再往上叠三层,一张嘴就成了一支乐队。

本文是产品说明书;给开发者的实现说明在最后。

## 1. 它能做什么

- 四条独立轨道,每轨最长 8 小节。
- 一键录音:设备擦除目标轨、倒计时一小节、严格录满一个循环长度,然后自动开始播放。
- 录音时喇叭静音,由屏幕充当视觉节拍器。
- 磁带效果:按住 UP,整段循环像磁带停转一样降速到 0.5 倍。
- 全部数据存在设备里。不需要 Wi-Fi、账号或云端。

## 2. 使用条件

| 项目 | 说明 |
| --- | --- |
| 设备 | FoloToy AI Passport(ESP32-C3,8 MB Flash) |
| 固件 | `FoloToy-AI-Passport-full.bin`,从 `0x0` 整片刷写 |
| 主机工具 | ESP-IDF 5.5.3(仅自行编译时需要) |
| 音频 | 内置麦克风与喇叭,不需要任何配件 |

整片刷写会替换固件;首次启动时会创建 `loops` 数据分区。其他固件留下的数据和本应用
格式不兼容,会被当作空套装忽略。

## 3. 第一次使用

1. 开机。屏幕显示 `LOOP PAD`、速度(`90 BPM`)、四条空的轨道行,状态为 `就绪`。
2. **长按 OK**。屏幕先显示 `准备中`(擦除目标轨),再进入 `倒计时`,有大号拍号和咔哒声。
3. 打一小节嘴鼓。倒计时一小节之后,正式录满四小节;大号数字就是你正在打的拍。
4. 录音自动停止并立即开始循环播放,第 1 轨状态变成 `播放`。
5. 短按 DOWN 选中第 2 轨,**长按 OK**,对着同样四小节哼一条贝斯。第 3、4 轨同理。
6. 短按 OK 暂停/继续播放;按住 UP 可以听到磁带降速。
7. 长按 DOWN 进入设置页;在设置页长按 OK 返回。

录音一结束就会写入 Flash,断电后下次开机能接着玩。

## 4. 按键说明

### 演奏页

| 操作 | 作用 |
| --- | --- |
| UP / DOWN 短按 | 选择轨道(上/下) |
| OK 短按 | 播放 / 停止 |
| OK 长按 | 录制选中轨道(原有内容会被覆盖) |
| UP 长按(按住不放) | 磁带效果:降到 0.5 倍速,松手恢复 |
| DOWN 长按 | 进入设置页 |

### 录音页

| 操作 | 作用 |
| --- | --- |
| OK 短按 | 取消本次录音;如果已有循环,会继续播放 |

录音时喇叭是静音的,这是有意为之:麦克风和喇叭在同一个塑料腔体里,边放边录必然啸叫。
节奏交给屏幕上的视觉节拍器。正式录音前会先响一小节咔哒声,方便你对准速度。

### 设置页

| 行 | OK 短按 |
| --- | --- |
| 速度 | 下一档(60~140 BPM,步进 10) |
| 小节 | 循环 1 → 2 → 4 → 8 |
| 鼓 / 贝斯 / 和声 / 人声 音量 | 循环 0 → 25 → 50 → 75 → 100 % |
| 清空当前轨 | 擦除演奏页上选中的那一轨 |
| 清空全部 | 擦除四轨并停止播放 |
| 返回 | 回到演奏页 |

速度和小节数只有在四轨全空时才能改,否则该行显示 `需先清空`。音量在离开设置页时保存。

## 5. 界面

- **演奏页**:顶部是速度和电量,下面是四个拍点,再下面是四条轨道行(带音量条),
  最底部两行提示会在"录音"和"设置/变速"两种提示之间轮流切换。
- **录音页**:整屏显示。大号数字是拍号,副标题显示正在录第几小节,两根进度条分别是
  循环进度和输入电平。
- **设置页**:九行列表,选中行用琥珀色高亮。
- **提示浮层**:底部短暂出现一句话,例如 `已停止`、`已清空`、`先录一轨`。

## 6. 循环长度与存储

循环长度由速度和 小节数决定,并对齐到 15 ms 的音频块,这样录音和混音永远整块处理。

| 速度 | 小节 | 时长 |
| --- | --- | --- |
| 120 BPM | 1 | 2.0 秒 |
| 90 BPM | 4 | 10.7 秒 |
| 60 BPM | 4 | 16.0 秒 |
| 60 BPM | 8 | 32.0 秒(上限) |

| 分区 | 偏移 | 大小 | 用途 |
| --- | --- | --- | --- |
| `nvs` | `0x9000` | 24 KB | 保留 |
| `phy_init` | `0xf000` | 4 KB | 射频校准 |
| `factory` | `0x10000` | 3 MB | 应用 |
| `loops` | `0x310000` | 4.06 MB | 两份超级块 + 四个 1 MB 轨道槽 |

每轨以 16 kHz / 16-bit 裸 PCM 保存(每秒 32 KB)。超级块记录速度、小节数、轨道状态、
音量与峰值电平,并且交替写入两个 4 KB 扇区:保存过程中掉电,上一份仍然可读。

## 7. 声音设计

- 16 kHz、16-bit 单声道。这是故意的 lo-fi:保留底噪和略微发闷的高频,让嘴鼓听起来
  更像采样器而不是录音笔。
- 回放时按录音峰值做归一化,轻声的一轨最多可以提升 8 倍,不会改文件本身。
- 每轨首尾各做 5 ms 淡入淡出,消掉循环接缝的咔哒声。
- 录音不会"超长":速度和 小节数的范围已经把循环长度限制在 32 秒以内。

## 8. 已知限制

- **录音时听不到监听。** 叠录时听不到已有的轨道,只能看屏幕节拍。硬件上增加耳机口是
  根治办法。
- 16 kHz 没有 8 kHz 以上的内容,录下来的踩镲会发闷;建议用合成噪声代替采样。
- 喇叭很小,低音贝斯主要听到的是谐波,而不是基频。
- 磁带效果最低只到 0.5 倍速,不是完全停转。

## 9. 故障排查

| 现象 | 原因与处理 |
| --- | --- |
| 屏幕一直黑 | 背光没点亮;重新整片刷写并重新上电。若仍黑,说明面板初始化失败,看串口日志。 |
| 显示 `存储不可用` | 找不到 `loops` 分区。用合并镜像从 `0x0` 刷写,让分区表一起写入。 |
| 显示 `音频不可用` | ES8311 编解码器初始化失败,检查串口日志里的 I2C 错误。 |
| 录不到声音 | 离麦克风 20 cm 以内;录音页的电平条应该有反应。 |
| 循环听起来不齐 | 四轨都从同一个采样零点开始,速度不会漂移;如果感觉不齐,是那一次录音本身没踩准节拍。 |
| 设置里的速度显示 `需先清空` | 还有轨道有内容;先清空再改速度或小节数。 |

## 10. 实现说明

```text
main/loop_core.c   纯逻辑:循环长度、节拍定位、增益、CRC、超级块
main/loop_store.c  裸分区读写、超级块 A/B 提交
main/loop_audio.c  音频任务:擦除、倒计时、录音、四轨混音、磁带效果
main/loop_ui.c     LVGL 界面与视觉节拍器
main/loop_app.c    按键队列、页面状态、电量轮询
assets/fonts/      生成的 16/24/32 px 中文字库(285 个码位)
tools/loop_font.py 字库生成器,逐像素与 FreeType 结果比对
tests/             循环逻辑与字库覆盖的主机测试
```

- 音频只有一个任务,固定 240 帧一块。录音时每块写 480 字节,播放期间绝不擦除 Flash。
- `loop_core.c` 不依赖 ESP-IDF,由 `tests/test_loop_core.c` 覆盖;
  改了界面文案却没重新生成字库时,`tests/test_lofi_font_coverage.py` 会失败。
- `sdkconfig.defaults` 里关掉了蓝牙:采样器完全离线,把 RAM 留给音频和界面。
